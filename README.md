# Живые лидмагниты

Кабинет эксперта, где собирают «живой лидмагнит»: ИИ-консультант в Telegram, MAX или ВКонтакте.
Человек пишет боту — консультант разговаривает с ним по вашему сценарию, присылает ролики и материалы,
делает рассылки и ведёт к покупке курса. Все разговоры видны в кабинете.

## Что нужно

- **Docker** с Docker Compose v2. На Mac и Windows — Docker Desktop, на сервере Linux — пакет `docker-ce`.
- **Ключ DeepSeek** — на нём работает консультант. Получить: [platform.deepseek.com](https://platform.deepseek.com) → API keys.
  Ключи Together и OpenRouter необязательны: это запасные провайдеры той же модели.
- **Для мессенджеров — сервер с доменом.** Telegram, MAX и VK присылают сообщения на публичный адрес `https://…`.
  На своём компьютере кабинет работает, но боты сообщений не получат.

PostgreSQL ставить не нужно: он запускается в Docker вместе с приложением.

## Установка

```bash
git clone https://github.com/ykurilov/livem-open.git && cd livem-open
./install.sh
```

Скрипт спросит три вещи:

1. Вашу почту — по ней вы будете входить в кабинет.
2. Ключ DeepSeek. Ввод скрыт.
3. Домен сервера. На своём компьютере нажмите Enter.

Дальше он сам создаст файл настроек `.env` со случайными ключами, соберёт и запустит приложение
и попросит придумать пароль. Первая сборка идёт 5–10 минут.

**На сервере** до запуска направьте домен на адрес сервера (запись A у регистратора) и откройте порты 80 и 443.
Сертификат HTTPS получит встроенный Caddy, отдельный Nginx не нужен.

## Первый вход

Откройте адрес, который скрипт показал в конце:

- на своём компьютере — [http://localhost:3000](http://localhost:3000);
- на сервере — `https://ваш-домен`.

Введите почту и пароль. Сессия живёт 30 дней.

- **Забыли пароль или хотите сменить** — `docker compose exec web node dist/set-password.js ваша@почта`.
- **Добавить ещё человека** — допишите его почту через запятую в `ALLOWED_EMAILS` в `.env`,
  выполните `docker compose up -d` и задайте ему пароль той же командой.
- **Выйти на всех устройствах** — поменяйте `AUTH_COOKIE_SECRET` в `.env` и выполните `docker compose up -d`.

После пяти неверных паролей подряд вход с этого компьютера закрывается на 15 минут.
Пароли хранятся только в виде хеша.

> Кабинет по адресу вида `http://192.168.…` не пустит: браузер не сохранит защищённую cookie.
> Заходите через `localhost` на том же компьютере или через `https://` на сервере.

## Мессенджеры

Ботов подключают в кабинете, в разделе «Боты». Нужен сервер с доменом: в `.env` должен стоять
`PUBLIC_BASE_URL=https://ваш-домен` (скрипт ставит его сам, если вы назвали домен).

**Telegram.** Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, придумайте имя.
Он пришлёт токен вида `123456789:AA…` — вставьте его в кабинете.

**MAX.** Создайте бота в кабинете [Max для бизнеса](https://business.max.ru) и скопируйте его токен в кабинет.

**ВКонтакте.** В своём сообществе:

1. Управление → Сообщения: включите «Сообщения сообщества».
2. Там же «Настройки для бота»: включите «Возможности ботов». Без этого у бота не будет кнопок.
3. Управление → Дополнительно → Работа с API → Ключи доступа → «Создать ключ».
   Отметьте три права: управление сообществом, сообщения сообщества, фотографии.
4. Вставьте ключ в кабинет. Если какого-то права не хватает, кабинет скажет какого.

**Тревоги о сбоях.** Создайте у @BotFather отдельного бота, впишите его токен в `ALERT_BOT_TOKEN`
и выполните `docker compose up -d`. Номер чата, куда писать, укажите в кабинете: «Настройки» → «Куда слать тревоги».

## Оплата через GetCourse

Консультант может узнавать, что человек оформил и оплатил заказ. В GetCourse создайте процессы
«заказ создан» и «заказ оплачен» с вызовом адреса:

```
https://ваш-домен/api/integrations/getcourse/<GETCOURSE_WEBHOOK_SECRET из .env>
```

Секрет никому не показывайте: по нему приложение отличает настоящие уведомления.

## Команды на каждый день

```bash
docker compose ps                     # что запущено
docker compose logs -f web worker     # журнал
docker compose restart                # перезапуск
docker compose down                   # остановить (данные сохранятся)
git pull && ./install.sh              # обновиться до новой версии
docker compose exec postgres pg_dump -U livem livem > backup.sql   # резервная копия базы
```

Данные лежат в томах Docker `postgres-data` (база) и `app-data` (картинки рассылок).
Команда `docker compose down -v` удаляет их навсегда.

**Лидмагниты из консоли.** Для ИИ-агентов и скриптов есть команда
`docker compose exec -T web node dist/lead-magnet-cli.js`. Список действий она выводит без аргументов.
Пустой шаблон лидмагнита — `docs/lead-magnet-template.json`.

## Настройки

Все переменные с пояснениями — в [.env.example](.env.example). После правки `.env` выполните `docker compose up -d`.

Вход через свой сервис единого входа (OIDC) вместо пароля: `AUTH_MODE=sso` и переменные `AUTH_URL`, `AUTH_APP_URL`, `AUTH_CLIENT_ID`.

## Для разработчиков

Next.js 16, PostgreSQL и Drizzle, очередь pg-boss, pnpm.

```bash
pnpm install
docker compose -f docker-compose.dev.yml up -d   # база для разработки и тестов на порту 55439
cp .env.example .env.local   # DATABASE_URL=postgres://livem:livem@localhost:55439/livem, плюс ALLOWED_EMAILS,
                             # AUTH_COOKIE_SECRET, BOT_TOKEN_KEY и DEEPSEEK_API_KEY
pnpm db:migrate && pnpm password:set ваша@почта
pnpm dev                                          # кабинет
pnpm worker:dev                                   # работник: очередь, рассылки, ответы в мессенджерах
pnpm test:unit && pnpm test:integration && pnpm test:e2e
```

Проверка консультанта на разговорах с моделью-собеседником — `pnpm eval`, сценарии в `evals/scenarios`,
инструкция для оценки — `evals/judge.md`.
